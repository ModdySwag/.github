# Default community health files

The shared paperwork for every repository in this account.

GitHub applies the files in this repository to any repository that does not define its own copy,
so a bug report, a patch or a security report is handled the same way wherever it lands:

| File | What it does |
|:--|:--|
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to report a bug, ask for a feature and send a patch that will be accepted |
| [`SECURITY.md`](SECURITY.md) | Where to send a security report privately, what is in scope, and what is not |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | Bug and feature forms, and the links shown on the new-issue page |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | The checklist a pull request is measured against |

A repository can override any of these by adding its own file of the same name — ModFlow, for
example, carries a `CONTRIBUTING.md` and a `SECURITY.md` that match its own build.

The profile page is at [github.com/ModdySwag](https://github.com/ModdySwag), and the software is
at [moddys.net](https://www.moddys.net).
